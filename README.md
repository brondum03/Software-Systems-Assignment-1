# Software-Systems-Assignment-1
Shell Implementation

** Take a look at testing for the tests carried out to test the functionality from 6-8.

S3 Shell able to handle the following
1. Basic Commands
2. Commands with redirection
3. Support for cd (Including tilde (~))
4. Commands with pipes
5. Batched commands
6. Subshells (except process substitution take a look in testing.txt for the tests carried out)
7. Nested Subshells
8. Globbing ([], *, ? wildcards are handled)
